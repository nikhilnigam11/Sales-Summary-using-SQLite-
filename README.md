# 📄 Project Overview
This project is part of Task 7 at Elevate Labs.
It performs exploratory data analysis (EDA) on Superstore sales data using Pandas, SQLite, and Colab.
The goal is to extract key business insights, such as total sales, profits, best-performing products, top customers, and regional trends.

# 🏗️ Project Structure
superstore.csv → Raw sales data with ~51,000 rows and 27 columns.

superstore.db → SQLite database created from the CSV.

notebook.ipynb / colab notebook → Python code running queries, data cleaning, and visualizations.

# 🔍 Key Analyses
✅ Total Sales and Profit
✅ Top-Selling Product (by quantity)
✅ Maximum Profit Product (per year)
✅ Customer with the Maximum Single Purchase
✅ Regional and City-Level Sales and Profit Analysis
✅ Visualizations (bar plots) for total sales by region
✅ Top 5 and Bottom 5 Cities by Average Profit

📦 Requirements
